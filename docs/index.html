Ingeniería de mantenimiento

Qué aporta este fork

Seguridad

Correcciones de validación TLS, transferencia USB y extracción de archivos. Cambios sujetos a revisión y pruebas.

Compilaciones trazables

Integración continua, dependencias controladas, artefactos y sumas SHA-256 asociados a cada release.

Compatibilidad responsable

Pruebas para Horizon OS 23.0.1, Atmosphère 1.12.1 y Kefir 927, sin atribuir certificaciones no realizadas.

Colaboración abierta

Historial upstream preservado, reportes reproducibles, documentación y reconocimiento de autores originales.
